# AMIRAN TICKET — وب‌اپ آیفون

این همان برنامه است، ولی به‌صورت **وب‌اپ (PWA)**: روی آیفون با Safari باز می‌شود، با «Add to Home Screen» آیکون می‌گیرد و مثل یک برنامه‌ی معمولی (تمام‌صفحه، بدون نوار آدرس) اجرا می‌شود. نیازی به App Store، Mac یا حساب توسعه‌دهنده‌ی اپل نیست.

## ۱) آپلود روی GitHub Pages (یک‌بار، رایگان)
1. در GitHub یک ریپوی جدید بساز، مثلاً `amiran-ticket-web` (می‌تواند Public باشد).
2. **همه‌ی فایل‌های داخل این پوشه** را (نه خود پوشه را) در ریپو آپلود/Commit کن (با GitHub Desktop مثل پروژه‌ی اندروید).
3. در ریپو: **Settings ← Pages ← Source: Deploy from a branch ← Branch: main / (root) ← Save**.
4. بعد از ۱ تا ۲ دقیقه آدرس برنامه ساخته می‌شود:
   `https://<نام‌کاربری‌ات>.github.io/amiran-ticket-web/`

> آدرس باید `https` باشد (GitHub Pages خودش https است)؛ بدون https دوربین در Safari باز نمی‌شود.

## ۲) نصب روی آیفون
1. آدرس بالا را در **Safari** باز کن (حتماً Safari، نه Chrome).
2. دکمه‌ی اشتراک‌گذاری (مربع با فلش) ← **Add to Home Screen** ← Add.
3. از آیکون AMIRAN روی صفحه‌ی اصلی باز کن. بار اول اجازه‌ی دوربین را «Allow» بزن.
4. کد لایسنس را وارد کن (همان ۳ کد قبلی؛ همان قوانین: ۱۰ روزه حداکثر ۳ بار روی هر دستگاه، ۶ ماهه ۱ بار، دائمی).

## ۳) «ارسال به BC»
آدرس Web App همان Apps Script قبلی (`…/exec`) را یکی از این دو راه بده (فایل `Code.gs` قبلی بدون هیچ تغییری کار می‌کند):
- داخل برنامه: **تنظیمات ← آدرس سرویس BC**، یا
- در فایل `config.js` به‌جای `''` بنویس و دوباره آپلود کن.

## چطور کار می‌کند
- **اسکن:** با دوربین آیفون و کتابخانه‌ی ZXing (EAN، Code128، Code39، ITF، QR و …). کول‌دان ۵ ثانیه، ورود دستی، آخرین بارکد، کلید روشن/خاموش QR، هشدار تکراری — مثل نسخه‌ی اندروید.
- **ذخیره‌ی خودکار:** هر بارکد همان لحظه ذخیره می‌شود و تا وقتی خودت پاک نکنی در «فایل‌های ذخیره شده» می‌ماند.
- **جشنواره / عادی:** با دیتابیس جشنواره (فرمت `بارکد,تعداد`، ورود با رمز مدیریتی) جدا می‌شود؛ فقط فایل‌هایی که بارکد دارند ساخته می‌شوند؛ دیتابیس خالی = یک فایل ساده.
- **اشتراک‌گذاری:** از Share Sheet خود آیفون (AirDrop، Mail، Files، …). **ذخیره در فایل:** دانلود در Files (یا گزینه‌ی «Save to Files» در Share Sheet).
- **آفلاین:** بعد از اولین باز شدن با اینترنت، برنامه بدون اینترنت هم باز می‌شود (فقط «ارسال به BC» اینترنت می‌خواهد). با اینترنت، همیشه آخرین نسخه را می‌گیرد.
- **داده‌ها** فقط روی همین گوشی (حافظه‌ی مرورگر) هستند و به هیچ سرور دیگری نمی‌روند، مگر وقتی خودت «ارسال به BC» بزنی.

## محدودیت‌های آیفون (از خود iOS است)
- لرزش (vibration) در Safari وجود ندارد؛ به‌جایش **بوق کوتاه** پخش می‌شود.
- چراغ قوه از داخل وب‌اپ در iOS پشتیبانی نمی‌شود (دکمه فقط جایی نشان داده می‌شود که پشتیبانی شود).
- «روشن ماندن صفحه» از iOS 16.4 به بعد کار می‌کند.
- اگر برنامه را از صفحه‌ی اصلی حذف کنی یا «Clear Website Data» بزنی، **همه‌ی اطلاعات و لایسنس پاک می‌شود** (مثل حذف برنامه‌ی اندروید) و باید دوباره کد بزنی.
- اسکن بارکدهای خیلی ریز/کم‌کیفیت ممکن است از برنامه‌ی اصلی اندروید کندتر باشد.
